# AI-TestGuard

## Description
Projet de validation, robustesse et fiabilité
d'un modèle de détection de fraude bancaire.

## Objectifs
- Tester la qualité des données.
- Développer des tests unitaires.
- Évaluer les performances du modèle ML.
- Tester la robustesse et la reproductibilité.
- Automatiser les tests avec GitHub Actions.

## Technologies
- Python
- pandas et NumPy
- scikit-learn
- pytest et pytest-cov
- Git et GitHub Actions

## Jeu de données
Credit Card Fraud Detection - Kaggle
