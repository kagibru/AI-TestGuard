# Jeu de données

Source : Kaggle - Credit Card Fraud Detection

Fichier attendu : creditcard.csv

Le fichier CSV doit être placé dans ce dossier.

Il n'est pas versionné dans Git afin d'éviter
de publier inutilement des données volumineuses.

Variables :
- Time : temps écoulé
- V1 à V28 : composantes anonymisées
- Amount : montant de la transaction
- Class : classe cible (0 = normale, 1 = fraude)
